1. 0:00–0:30: показать README и выполнить `python -m auditlab.demo --seed 2026 --interaction fx_cutoff`. В первом наблюдении видны manifest, политика и бюджет; эталона нет.
2. 0:30–1:15: показать чтение таблиц, последовательность шагов и финальные findings с ID доказательств. Объяснить связку «счёт → платёж → курс → проводки → граница периода».
3. 1:15–1:45: открыть demo-trajectory.jsonl: нулевые исследовательские награды, финальная train-награда. Показать разделение evaluator service / agent adapter.

5. 2:30–3:00: открыть public/ и evaluator/ одного экспортированного эпизода. Объяснить, что evaluator/ не монтируется агенту при закрытом запуске. Указать ограничения из README.
